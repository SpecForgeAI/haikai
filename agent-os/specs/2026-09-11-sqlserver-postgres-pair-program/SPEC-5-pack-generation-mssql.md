# SPEC 5 — Pack generation for SQL Server (gate, type map, DDL, decisions, collation)

Design of record: shaping §5 items 2 and 5. Size: L. Depends on: S2 (+S0). Wave D (parallel with S4).

## Goal
`gateway/src/services/dbMigrationPack/**` generates a complete, validated Liquibase + data + sync +
translation-queue pack from a SQL Server scan, with every SQL-Server-only object either emulated or
surfaced as a decision with options — never manual residue.

## Tasks
- 5.1 Gate + IR: `inputs.ts` `GENERATOR_SUPPORTED_SOURCE_ENGINES` add `mssql`; system-object
  exclusion becomes engine-keyed: `systemObjects.ts` exports `isSystemObjectFor(engine, schema, name)`
  — Sybase = the existing curated list; MSSQL = schema ∈ {`sys`, `INFORMATION_SCHEMA`} or name in
  {`sysdiagrams`, `dtproperties`, `MSreplication_*`, `__RefactorLog`, `spt_*`} (keep the old
  `sybaseSystemObjects.ts` exports as re-exports). `parseQualifiedName` default schema `dbo` (both).
  IR gains per-column `collation`, `precision`, `computed.persisted`, `identity.seed/increment`,
  `default.expression`, per-index `filter`, `includeColumns`, `method` vocabulary, per-table
  `temporal`, `memoryOptimized`, per-object `extended` records.
- 5.2 Type map (`typeMapping.ts`): engine-keyed tables (`mapSourceType(engine, …)`). MSSQL rows:
  `int/smallint/bigint` same; `tinyint`→`smallint`; `bit`→`boolean`; `decimal/numeric(p,s)`;
  `money`→`numeric(19,4)`, `smallmoney`→`numeric(10,4)`; `float(n)`→`double precision` (n≤24 →
  `real`); `real`; `char(n)`→`char(n)` (bare → needs_decision as today); `nchar(n)`→`char(n)`;
  `varchar(n)`→`varchar(n)`; `varchar(max)`→`text`; `nvarchar(n)`→`varchar(n)`; `nvarchar(max)`→
  `text`; `text/ntext`→`text`; `binary(n)/varbinary(n)/varbinary(max)/image`→`bytea`;
  `date`→`date`; `time(p)`→`time(min(p,6))` (p=7 flagged precision_loss); `datetime`→`timestamp(3)`;
  `smalldatetime`→`timestamp(0)`; `datetime2(p)`→`timestamp(min(p,6))` (p=7 flagged);
  `datetimeoffset(p)`→`timestamptz(min(p,6))`; `uniqueidentifier`→`uuid`; `rowversion/timestamp`→
  needs_decision (`map_to_bytea` | `drop_column` | `application_managed`, as Sybase);
  `xml`→`xml`; `sql_variant`→ decision `sql_variant_column` (`jsonb` | `text` | `drop_column`);
  `hierarchyid`→`ltree` (extension prerequisite) ; `geography`→`geography` / `geometry`→`geometry`
  (PostGIS prerequisite; decision `spatial_column` offers `postgis` | `wkt_text` | `drop_column`);
  `sysname`→`varchar(128)`; user-defined alias types → base type + manifest note; table types →
  `user_defined_table_type` decision (composite type emission default). `SAFE_DEFAULT_REWRITES`
  add `sysutcdatetime→(now() AT TIME ZONE 'UTC')`, `sysdatetime→now()`, `newid→gen_random_uuid()`,
  `newsequentialid→gen_random_uuid()` (note: not sequential), `getutcdate`, `host_name`,
  `original_login→session_user`, `@@spid→pg_backend_pid()`. `COMPUTED_FN_TRANSLATIONS` add
  `iif→CASE`, `try_convert`, `concat`, `format` (decision). Unify the duplicate in
  `routineInvocationDescriptor.ts:102-158` onto `mapSourceType` (fix bare `char` → `char(1)` guess).
- 5.3 Liquibase (`liquibase.ts`): filtered index → `CREATE INDEX … WHERE <translated predicate>`
  (predicate through the check-expression translator; non-portable → `index_predicate` decision)
  — the ASE THROW stays for `sybase` only; INCLUDE columns → `INCLUDE (...)`; method vocabulary:
  clustered/nonclustered → btree (+ CLUSTER note), `columnstore` → btree + manifest note
  `columnstore_dropped_to_btree` + decision `columnstore_index` (`btree` | `skip`), `xml`/`spatial`
  → GIN/GIST via decision, `fulltext` → item-5 emulation (5.5); name scoping: MSSQL constraints are
  schema-scoped (PK/UQ/FK/CHECK/DEFAULT names) and indexes table-scoped → rename only index
  collisions; computed columns: persisted → `GENERATED ALWAYS AS (…) STORED`, non-persisted →
  PG 18 `VIRTUAL`; defaults + check constraints from the catalog (real data, not regex);
  identity seed/increment → `GENERATED BY DEFAULT AS IDENTITY (START WITH s INCREMENT BY i)`;
  sequences with full detail; FK actions incl. `SET DEFAULT`; disabled/untrusted FK/CHECK →
  emitted `NOT VALID` + note; rowguidcol note; sparse → plain.
- 5.4 Collation (item 2): pack-wide decision `collation` default resolution `citext` when the
  DB or any string column collation is `_CI_`; per-column emission: `citext` for affected
  char/varchar/nvarchar (UNIQUE/PK on citext preserved; `char(n)` CI → `citext` + length CHECK),
  ICU option → `COLLATE "und-x-icu-ci"` created via `CREATE COLLATION haikai_ci (provider=icu,
  locale='und-u-ks-level2', deterministic=false)` in changeset 000 + the documented LIKE/regex
  restriction in the manifest; third option = accept CS. Data parity reads the decision to enable
  `collation-case` only on affected columns (manifest `collation_affected_columns`).
- 5.5 Item-5 emulations + decisions (new pack decision categories + AMS `chk_dmpd_category`
  extension changeset 232: `temporal_table`, `clr_object`, `service_broker`, `filestream`,
  `fulltext_index`, `xml_method`, `sql_variant_column`, `hierarchyid_column`, `spatial_column`,
  `columnstore_index`, `memory_optimized_table`, `user_defined_table_type`, `synonym`,
  `index_predicate`, `cross_database_reference` (named OUT), `indexed_view` (named OUT)):
  - temporal: default `emulate_history_table` → emit `<t>_history` table (same columns +
    `valid_from`/`valid_to timestamptz`), `haikai_temporal_versioning()` trigger function + AFTER
    UPDATE/DELETE trigger, period columns on the base table, `FOR SYSTEM_TIME` guidance rule
    `MSPG.TEMPORAL.001` (rewrite to `WHERE valid_from <= t AND valid_to > t` over `UNION ALL`);
    alternatives `drop_history` | `application_managed`;
  - full-text: default `tsvector_gin` → generated `tsvector` column + GIN + `contains_freetext`
    rewrite guidance (`to_tsquery`), alternative `drop_index`;
  - xml methods: guidance (`xpath()`/`xmltable`) rule `MSPG.XML.002` + queue entries typed
    `xml_method` for routines using them;
  - hierarchyid → `ltree` (extension `ltree` prerequisite) default, `text` alternative;
  - spatial → PostGIS default, `wkt_text`, `drop_column`;
  - sql_variant → `jsonb` default (`{"type":…,"value":…}` load form), `text`, `drop_column`;
  - CLR / Service Broker / FILESTREAM → decision with `rewrite_in_app` (default; the body/
    assembly name carried into the work-item), `external_service`, `drop`; a translation-queue
    row of kind `clr_object` / `service_broker_object` so the workbench shows them with the named
    untranslatable reason when `drop`/`rewrite_in_app` is not chosen;
  - memory-optimized → plain table + note; synonyms → `CREATE VIEW` (table synonyms) or
    a `search_path` note (schema synonyms) via decision default `view`;
  - user-defined table types → `CREATE TYPE … AS (…)` composite + `tvp_param` guidance.
  Extend translation kinds (AMS `chk_dmpt_kind` in the same changeset): `table_valued_function`,
  `scalar_function`, `synonym`, `user_defined_table_type`, `sequence`, `clr_object`,
  `service_broker_object`, `temporal_history`. Gateway `TRANSLATION_KINDS` + `KIND_INSTRUCTIONS`
  (prompt text lands in S6; S5 registers kinds + emission order `050`).
- 5.6 Data scripts + sync (`dataScripts.ts`, `syncPack.ts`): MSSQL extract expressions —
  money `CONVERT(numeric(19,4), col)`, datetime family `CONVERT(varchar(27), col, 121)`,
  datetimeoffset `CONVERT(varchar(34), col, 127)`, binary `'\x' + LOWER(CONVERT(varchar(max), col, 2))`,
  bit `CAST(col AS int)`, uniqueidentifier `LOWER(CONVERT(char(36), col))`, xml `CONVERT(nvarchar(max), col)`,
  spatial `col.STAsText()`, hierarchyid `col.ToString()`; `DATETIME_FAMILY_BASES` per engine
  (datetime2/datetimeoffset); script headings "SQL Server extract"; bcp guidance replaces isql;
  `syncPack.ts` reconciliation SQL section "SQL Server (SOURCE) — sqlcmd" with `GO`.
- 5.7 Validation + harvest: `packValidation.ts` `findSystemReferences` engine-keyed (MSSQL: `sys.`
  and `INFORMATION_SCHEMA.` references), 63-byte identifier gate unchanged (SQL Server allows 128);
  `dbSchemaHarvest.ts` engine from the manifest/context; harvest modal payload engine-aware (S7 UI).
  `callSiteCompatibility.ts:76` error-number regex per engine (MSSQL: `SQLServerException`,
  `getErrorCode()`, numbers 50000+ for THROW, 547/2627/2601 constraint families).
- 5.8 Tests: `dbMigrationPackGenerationMssql.test.ts` (full pipeline over the vendored WWI IR
  fixture → pack validates), type-map rows, filtered/INCLUDE index emission, temporal emulation
  files, collation citext/ICU emission, item-5 decisions open → Migrate blocked via the existing
  open-decisions gate, system-object filter, extract expressions, `dbMigrationPackSybase*` untouched.
