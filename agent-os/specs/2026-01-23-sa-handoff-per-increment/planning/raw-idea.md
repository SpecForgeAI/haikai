title: Software Architect Handoff Per Increment + Implementer JSON Contract

intent: |
  After an Implementation Plan is generated by the Product Owner, introduce the Software Architect
  (Implementation LLM) interaction loop per increment:
    - Send the active increment's proposedFinalSubFeatureDefinition to the Software Architect
    - Receive structured JSON responses (including openQuestions)
    - Populate the Questions table with Software Architect questions
    - Allow the Tool User to answer via the existing "Answer Open Questions" workflow

User decisions from shaping:
- SA Trigger: Auto-trigger on plan generation (first increment immediately after plan)
- Response Type: Simple structure (schemaVersion, message, openQuestions[] only)
- Question Scope: Store incrementId on each question (filter by active increment)
- Status Indicator: Badge on IncrementCard ('In Clarification' or 'Ready')
- Ready State: Show 'Ready' indicator, await next phase (no auto-advance)
