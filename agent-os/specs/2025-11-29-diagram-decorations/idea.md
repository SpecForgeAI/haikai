# Raw Idea

Add a "decorations" feature to the Diagram view that allows users to place purely visual elements (BOX and LINE types) on the canvas that are NOT tied to the architecture meta-model. These elements are used for grouping, annotating, and clarifying diagrams. Includes:
- JSON schema extension with decorations array
- BOX decorations (optional text, background, border styling)
- LINE decorations (polyline with optional label)
- Bottom panel UI for adding decorations and editing text
- Selection, move, resize, and style editing via inspector
- Z-ordering relative to nodes/edges
